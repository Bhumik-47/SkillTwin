# AI Grounded Explanation & Diagnostic Agents

The `backend/agents/` package provides specialized LLM agents powered by the **Google Gemini API** (`@google/genai` / `google-genai`).

These agents interpret cognitive state transitions, explain why learning paths were adapted, and formulate next-best action recommendations for learners.

---

## 🎯 Grounding Invariant (Zero-Hallucination Policy)

Every explanation generated by these agents must be **strictly grounded** in deterministic state data passed from the ML engine and DAG planner:

1. **Path Repair Explanations**:
   - Must explicitly reference the triggering skill (`trigger_skill_id`).
   - Must quote the prior and posterior mastery probabilities ($P(L_t) \rightarrow P(L_{t+1})$).
   - Must cite the exact repair metrics (`touched_node_count`, `inserted_nodes`, `reordered_nodes`).

2. **Next-Step Recommendations**:
   - Must populate `grounding_metadata` with verified values (`current_mastery_prob`, `prerequisite_skills_mastered`, `target_goal_relevance_score`, `bkt_evidence_summary`).
   - The textual explanation must not invent prerequisite dependencies, test scores, or completion percentages not found in the metadata.

---

## 📂 Key Components

- **`explanation_agent.py`**:
  - Generates clear, pedagogical rationales for why remedial steps were inserted or prerequisites unlocked.
- **`recommendation_agent.py`**:
  - Analyzes open path nodes and recent performance to curate top-3 recommended actions (`learn`, `reinforce`, `assess`, `skip`).
- **`prompts.py`**:
  - Structured prompt templates enforcing JSON output schemas with strict grounding constraints.
